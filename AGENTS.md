# Engenharia de Agentes do Projeto

Este repositório foi estruturado para cumprir a exigência de uso de agentes distintos, incluindo um agente de teste e validação.

## Agentes criados

### 1) Agent Architect
- Papel: planejar a arquitetura do sistema, definir persistência, autenticação e integrações.
- Harness: planejamento de solução e revisão de requisitos do projeto.
- Skills usadas: `skills/architecture.md`, `skills/cloudflare.md`.

### 2) Agent Frontend
- Papel: desenhar a interface em HTML5, CSS3 e JavaScript vanilla, com cálculo de porções em tempo real.
- Harness: desenvolvimento do frontend e manipulação direta do DOM.
- Skills usadas: `skills/frontend-ui.md`, `skills/ingredient-scaling.md`.

### 3) Agent Test & Validation
- Papel: validar regras de negócio como escalonamento de ingredientes e busca por filtros.
- Harness: Node.js test runner (`node --test`).
- Skills usadas: `skills/testing.md`, `skills/validation.md`.
